# Publicar y presentar la demostración de Media Copilot

## Estado
La página `docs/index.html` es una demostración interactiva autónoma y ficticia, probada en navegador Chromium mediante GitHub Actions. No representa certificación de producción.

## Publicación en GitHub Pages
1. Abrir el repositorio `90oso/tvn-media-copilot` → **Settings** → **Pages**.
2. En **Build and deployment** elegir **Deploy from a branch**.
3. Seleccionar rama `feat/commercial-demo-2026-10` y carpeta **/docs**, luego guardar.
4. Verificar el despliegue en **Actions** y abrir la URL cuando GitHub la publique.
5. Opcional: revisar y fusionar el PR, y cambiar Pages a rama `main`, carpeta **/docs**.

**No publicar credenciales, bases reales ni información personal.** La demo se publica en GitHub Pages; la aplicación de producción necesita hosting y controles independientes.

## Guion de demostración
1. En Radar seleccionar persona comercial.
2. Buscar **empleo** y abrir ficha de evidencia.
3. Preparar brief y exportar Markdown.
4. Buscar texto inexistente: se muestra abstención.
5. Cambiar fecha para filtrar señales de ejemplo.
6. Explicar que el backend real también filtra el snapshot por fechas.

## Mensaje para comprador
Vigilancia informativa por nichos con informes trazables, no reventa indiscriminada de noticias.

## Advertencias
Demo con señales ficticias y plantilla determinista; el producto necesita fuentes configurables, licencias y tenants.
